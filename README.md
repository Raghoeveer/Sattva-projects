# Sattva Projects

Channel-partner marketing site for Sattva Group projects. Plain static HTML, generated by a small stdlib-only Python script.

## Build

```sh
python3 build.py          # writes the deployable site to public/
cd public && python3 -m http.server 8000   # preview at http://localhost:8000
```

Deploy the `public/` folder to any static host (Netlify, Cloudflare Pages, Hostinger, etc.). `404.html` sits at the root for hosts that pick it up automatically.

## Where things live

| What | File |
|---|---|
| Brand name, domain, phone, WhatsApp, email, RERA numbers, Web3Forms key, GA4 id | `src/site.json` |
| Page shell (`<head>`, meta, OG tags) | `src/layout.html` |
| Header, footer, sticky bar + enquiry modal, forms | `src/partials/` |
| Page content | `src/pages/` (each starts with a `<!--meta {...} -->` block) |
| CSS / JS / images | `src/static/` |

`sitemap.xml`, `robots.txt` and `site.webmanifest` are generated on every build. FAQ schema is generated from each page's visible `<details>` FAQ when its meta has `"faq_schema": true`.

## Renaming the site

Edit `site_name`, `site_tagline` and `base_url` in `src/site.json`, then run `python3 build.py`.

## Projects

`src/projects.json` lists every project (name, locality, corridor, type, sizes, price, status) and the corridor groupings. From it the build generates:

- the area-grouped directory on `/projects/`
- the featured grid on the home page (pick slugs with `"featured"` in `src/pages/index.html`)
- the "Other Sattva projects worth a look" block on each project page (same corridor first, then same type)
- breadcrumb + Residence JSON-LD and the project dropdown on the contact form

### Adding a project

1. Add an entry to `src/projects.json`.
2. Put images in `src/static/images/<slug>/`, including `<slug>-card.webp` (800×500) and `<slug>-share.jpg` (1200×630).
3. Copy an existing page in `src/pages/projects/` to `<slug>.html`, set `"path"`, `"project"`, `"configs"` and `"rera_html"` in the meta block, and write fresh content.
4. Run `python3 build.py`.
